# Sentiment Analysis of IMDB Reviews

Classify movie reviews as positive or negative using a balanced set of 50,000 labelled reviews.

## Approach

- Text cleaning and exploratory analysis
- Word2Vec embeddings and SentiWordNet lexicon features
- Logistic Regression, Naive Bayes and ensemble methods

## Results

Accuracy between about 0.67 and 0.84 in the saved notebook output.
